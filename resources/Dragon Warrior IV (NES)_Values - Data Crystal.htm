Day/Night Cycle

Staying at the Inn sets the time to $28.

The day/night cycle resets after $cb.

Value Length Description
$00 - $27 40 ($28) Day
$28 - $77 80 ($50) Day - After staying at Inn
$78 - $7b 4 Afternoon
$7c - $7f 4 Dusk
$80 - $83 4 Evening
$84 - $bf 60 ($3c) Night
$c0 - $c3 4 Pre-dawn
$c4 - $c7 4 Dawn
$c8 - $cb 4 Morning
$cc - $ff 52 ($34) ...

Items

The item index only uses the bottom 7 bits so values range from $00 to $7f.

$51 is a blank item separating the equipment ($00 - $50) and regular items ($52 - $7e). [TODO: does this represent something special?]

$7f represents "no item in slot".

In the item bags, the high bit %1000_0000 indicates that the item is equipped. So, to get the equipped value add $80 to the item index.
